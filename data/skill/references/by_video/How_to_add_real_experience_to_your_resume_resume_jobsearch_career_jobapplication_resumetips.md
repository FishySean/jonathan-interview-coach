## Core principles

- **You can’t always be employed, but you can always be hustling.**
- No experience? **Make your own** and upgrade the resume — even in a single day.
- Use **theforage.com** (free): hands-on projects from JP Morgan, Pepsi, BCG, etc. → hours → certification + company name on resume.
- Resume points emphasize: **problem solved, key skills used, expected achievement** from the project.
- Bonus: ATS match boost via job title, key skills, and company name.

## Interview philosophy

Experience is manufacturable proof, not only W-2 history. Structured virtual projects create legitimate project-section lines and relevance signals for both humans and ATS.

## Evaluation criteria

Strong project bullets:

- Problem solved
- Key skills
- Expected / outlined achievement
- Recognizable company/program name
- ATS-relevant title/skills

## Common candidate mistakes

- Waiting to be employed before adding experience
- Completing Forage but not translating into problem/skills/achievement bullets
- Ignoring ATS relevance from company name + skills

## Follow-up questions

- “Which Forage project maps to my target role?”
- “Does my bullet show problem + skills + achievement?”
- “Will ATS see title/skills/company names that match the JD?”

## Answer frameworks

1. Complete Forage (or similar) project → cert  
2. Project section bullet: problem → skills → achievement  
3. Leverage company name + skills for ATS
